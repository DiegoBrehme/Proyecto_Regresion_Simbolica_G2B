## Cómo trabajar
Cada repo hijo es independiente (tiene su propio README y equirements).  
No versionamos ambientes virtuales ni artefactos pesados; solo el código y documentación necesarios.

## Agregar un NUEVO repositorio al ecosistema
1. Crea el repo nuevo en GitHub (por ejemplo: Proyecto_Regresion_Simbolica_<nombre>).
2. Vuelve a este repo padre y **edita este README** para añadir el link en la sección *Repositorios del proyecto*.
3. (Opcional) agrega notas en docs/.

## Sugerencias
- Usa Issues y un **Project board** en este repo padre para coordinar tareas globales.
- Datos grandes: no subir a Git; usar scripts para generarlos o Git LFS si es imprescindible.
